1. `git init`: Initializes a new git repository.
2. `git add`: Stages changes to prepare them for commit.
3. `git commit`: Saves staged changes to the repository history.
4. `git status`: Shows the current state of the working directory and staging area.
5. `git log`: Shows the commit history.
6. `git clone`: Clones a remote repository onto your local machine.
7. `git pull`: Fetches and merges changes from a remote repository into your current branch.
